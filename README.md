# チームタスクボード

チームのタスクと依頼を共有するボードです。
アプリ: https://takashikatsuhara.github.io/team-taskboard/

## 初回セットアップ（各自の端末で1回だけ・約3分）

1. 上のURLを開く
2. 右上の「**設定**」を開き、「GitHub同期」に管理者から共有された3つの値を入力して保存
   - GitHubユーザー名（owner）
   - データ用リポジトリ名
   - アクセストークン
3. 右上のセレクタで**自分の名前**を選ぶ
4. スマホの場合はホーム画面に追加すると便利です
   - iPhone: Safariの共有ボタン →「ホーム画面に追加」
   - Android: Chromeのメニュー →「ホーム画面に追加」

## 使い方

- **タスク追加**: 一番上の入力行にタイトルを入れて Enter（担当を他の人にすれば依頼になります）
- **完了**: 左の丸チェック
- **着手**: 「未着手」をクリックすると「進行中」に切り替え
- **NEW** バッジ: 前回開いたあとに自分に振られた依頼
- 〆切の色: 赤=期限切れ / 濃青=今日 / 淡青=翌営業日

※ このリポジトリにはアプリのコードのみが含まれます。タスクデータは別のプライベートリポジトリに保存されます。
